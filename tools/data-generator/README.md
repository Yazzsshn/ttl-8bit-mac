# Data generator / Veri üretici

**EN:** Open `index.html` in a browser. It generates single-colour training images (light, dark, faded and shaded tones of red, green, blue and yellow) and mixed 5×5 test scenes, and downloads them as one `foto.zip` that the notebook in `pre-training/` reads directly. Everything runs in the browser; nothing is uploaded.

**TR:** `index.html` dosyasını tarayıcıda aç. Kırmızı, yeşil, mavi ve sarının açık, koyu, soluk ve gölgeli tonlarından tek renkli eğitim görselleri ve karışık renkli 5×5 test sahneleri üretir; hepsini `pre-training/` klasöründeki defterin doğrudan okuduğu tek bir `foto.zip` olarak indirir. Her şey tarayıcıda çalışır, hiçbir şey yüklenmez.

File names / Dosya adları: `foto/egitim/kirmizi_1.png`, `foto/sahne/sahne_01_mavi.png`
